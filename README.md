### Yep A Title

This repo is mostly for learning the basics of the basics with Graphics Programming.

Most of the excercises from the LearnOpenGL book were bolted onto one another instead of in separate folders so keep that in mind.

Also most of the work was down in the c-gl folder. Makefiles are used to build each of the sub projects and all vendored and "shared" libs are in each sub exercise.
Make sure you have system packages installed.

There is a small breakout game in odin as well.
